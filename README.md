Print-Price: Калькулятор стоимости печати баннеров

Краткое описание проекта

Print-Price — это легковесное одностраничное веб-приложение, разработанное для быстрого и удобного расчёта стоимости печати баннеров. Приложение позволяет пользователям вводить параметры заказа (материал, размеры, количество, опции люверсов и макета) и мгновенно получать итоговую стоимость. Проект также включает защищённую административную панель для управления ценами.

Проблема, которую решает проект

Проект решает проблему ручного и трудоёмкого расчёта стоимости печати баннеров, который часто требует учёта множества переменных. Он автоматизирует этот процесс, предоставляя точный и быстрый инструмент для клиентов и менеджеров. Наличие административной панели позволяет владельцам бизнеса гибко управлять ценовой политикой, сохраняя конфиденциальность коммерческих данных.

Установка и локальный запуск

Поскольку проект полностью клиентский, для его запуска не требуется сервер.

1. Клонируйте репозиторий:

```bash
git clone https://github.com/Ale007XD/Print-Price.git
cd Print-Price
```

2. Откройте `index.html`

Просто откройте файл `index.html` в вашем веб-браузере. Все необходимые скрипты и стили будут загружены автоматически.

> Примечание: Для административной панели откройте `admin.html`. Для работы админ-панели требуются зашифрованные файлы цен, которые генерируются только при деплое через GitHub Actions и используют секреты репозитория. Локальный запуск `admin.html` без этих файлов не позволит войти в систему.

Настройка

Публичный калькулятор

Настройка осуществляется через файл `prices.json`:

Параметр	Описание	
`materials`	Массив объектов с `id`, `name` (название материала) и `price` (цена за м²)	
`grommets`	Объект со стоимостью люверсов: `none`, `corners` (4 по углам), `perimeter` (по периметру с `pricePerPiece` и `step`)	
`cutting`	Объект со стоимостью резки (`pricePerMeter`)	
`layout`	Правила ценообразования для макета: `small`, `medium`, `large` с `maxArea` и `price`/`pricePerSqM`	

Пример `prices.json`:

```json
{
  "materials": [
    {"id": "banner_340", "name": "Баннер 340гр.", "price": 250},
    {"id": "banner_440", "name": "Баннер 440гр.", "price": 300},
    {"id": "mesh_300", "name": "Сетка 300гр.", "price": 350}
  ],
  "grommets": {
    "none": {"name": "Без", "price": 0},
    "corners": {"name": "4 по углам", "price": 50},
    "perimeter": {"name": "По периметру", "pricePerPiece": 10, "step": 0.25}
  },
  "cutting": {"pricePerMeter": 20},
  "layout": {
    "small": {"maxArea": 1, "price": 500},
    "medium": {"maxArea": 5, "pricePerSqM": 150},
    "large": {"pricePerSqM": 100}
  }
}
```

Административная панель

Настройка через секреты GitHub Actions:

Секрет	Описание	
`ADMIN_LOGIN`	Логин для доступа к админ-панели	
`ADMIN_PASSWORD`	Пароль для доступа к админ-панели	
`ADMIN_MATERIALS_JSON`	JSON-строка с данными о материалах	
`ADMIN_GROMMETS_JSON`	JSON-строка с данными о люверсах	
`ADMIN_CUTTING_JSON`	JSON-строка с данными о стоимости резки	

Эти секреты используются workflow `build-admin-secure.yml` для генерации зашифрованных файлов `admin-lock.json.enc`, `admin-prices.json.enc` и `admin-lock.salt`.

Ключевые функции

- ✅ Расчёт стоимости баннеров (материал, размеры, количество)
- ✅ Опции люверсов: без люверсов / 4 по углам / по периметру
- ✅ Опции макета: собственный или разработка макета
- ✅ Добавление нескольких позиций в один расчёт
- ✅ Удаление отдельных позиций
- ✅ Автоматический расчёт и отображение итоговой стоимости
- ✅ Экспорт расчёта в Markdown (копирование или скачивание `.md` файла)
- ✅ PWA: офлайн-доступ и установка на устройство
- ✅ Защищённая административная панель с отдельными ценами

API-эндпоинты

Проект не предоставляет RESTful API — это полностью клиентское приложение. Данные о ценах загружаются из локального файла `prices.json` (публичная версия) или дешифруются из зашифрованных файлов (административная панель).

Скриншоты (описание)

Известные ограничения / TODO

Ограничение	Описание	
Отсутствие серверной части	Упрощает деплой, но ограничивает хранение данных заказов и интеграции	
Валидация ввода	Требуется улучшение UX при некорректном вводе	
Отсутствие тестирования	Нет юнит-тестов и интеграционных тестов	
Несоответствие в расчётах	В публичной версии не учитывается стоимость резки (хотя есть в `prices.json`)	
Некорректные пути иконок PWA	В `sw.js` указаны `icon-192.png`/`icon-512.png` вместо `pwa-192x192.png`/`pwa-512x512.png`
